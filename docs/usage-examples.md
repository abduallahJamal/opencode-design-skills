# الاستخدام — أمثلة مطالبات جاهزة

> 🌐 **العربية** · [English](usage-examples.en.md)

أمثلة واقعية تُظهر كيف تُفعّل كل مهارة، وما الذي يُتوقّع من الوكيل فعله.

---

## 1) `sword` — Word

### مثال أ: تقرير سنوي
```text
use skill sword

اكتب تقرير أداء سنوي 2026 لشركة "النخبة للطاقة" (قطاع الطاقة المتجددة).
- الجمهور: مجلس الإدارة
- الستايل: Corporate، أزرق داكن + رمادي
- المحتوى: أكتبه من الصفر (نتائج تشغيلية ومالية متوسطة الحجم)
- 8–10 صفحات، عربي RTL
- يشمل: بطاقات مؤشرات، جدول مالي مقارن 2024–2026، رسم نمو الإيرادات
- الترويسة: اسم الشركة + "تقرير أداء سنوي 2026"
- التذييل: "سري — للاستخدام الداخلي" + ترقيم "صفحة X من Y"
```

**ما سيفعله الوكيل:** يطرح الأسئلة الناقصة (هل هناك شعار؟ بيانات مالية حقيقية أم افتراضية؟)، ثم يعرض موجز تصميم، ثم يولّد الملف، ثم يحوّله PDF ويراجع الصفحات.

### مثال ب: عرض سعر
```text
استخدم مهارة sword لإنشاء عرض سعر لخدمات استشارية.
الشعار: ./assets/logo.png — الألوان: #0F766E
العميل: شركة "أفق" — البنود: 4 خدمات، جدول تسعير بكميات
يُسلّم Word قابل للتعديل + ملاحظة أن الأسعار لا تشمل الضريبة.
```

> **ملاحظة مهمة:** إن ذكرت مسار شعار غير موجود، ستتوقف المهارة وتسأل — لا تخمّن مساراً.

## 2) `spdf` — PDF

### مثال أ: عرض فني للطباعة
```text
use skill spdf

عرض فني لمشروع توريد وتركيب أنظمة طاقة شمسية.
- A4، 6–8 صفحات، وجهين، عربي RTL
- ستايل: Corporate + لمسة فاخرة (ذهبي #B08D57 على #1C1917)
- يشمل: غلاف، صفحة بيانات المستند، فهرس بأرقام صفحات، بطاقات قدرات،
  جدول مواصفات تقنية، خط زمني للتنفيذ، صفحة تواصل
- الخط: IBM Plex Sans Arabic (مضمّن)
- يُطبع على ورق عادي — تجنّب الخلفيات الداكنة الكاملة
```

**ما سيفعله الوكيل:** يبني HTML+CSS، يولّد بـ WeasyPrint، يتحقق بـ `pdffonts` أن الخطوط مضمّنة، ثم يحوّل كل صفحة إلى PNG ويراجعها.

### مثال ب: تحويل مستند موجود
```text
لدي تقرير بصيغة .docx (./input/report.docx). أريد نسخة PDF احترافية منه:
غلاف بهوية الشركة، فهرس، وترقيم "صفحة X من Y". حافظ على المحتوى كما هو.
```

### مثال ج: تعديل PDF موجود
```text
عندي ./input/contract.pdf (12 صفحة). أريد:
1) إضافة تذييل "سري — نسخة رقم 4" + ترقيم على كل صفحة
2) دمج غلاف من ملف ./cover.pdf في البداية
3) كلمة مرور للفتح: ****
```

## 3) `shtml` — HTML

### مثال أ: داشبورد تقرير
```text
use skill shtml

صفحة تقرير HTML واحدة لنتائج الربع الثالث.
- عربي RTL، ملف واحد مستقل، بلا موارد خارجية
- ستايل Corporate أزرق #1D4ED8
- أقسام: Hero، 4 بطاقات KPI، جدول النتائج، رسم SVG، خط زمني للخطة، Footer
- متجاوبة على الجوال + وضع ليلي تلقائي + تنسيق طباعة
- المحتوى: بيانات افتراضية واقعية
```

### مثال ب: بروفايل شركة
```text
صفحة بروفايل شركة (Landing) لشركة مقاولات.
اللون الأساسي #B45309، خط Tajawal، أضف شعاراً من ./assets/logo.svg
أقسام: من نحن، الخدمات (6 بطاقات)، الأرقام، المشاريع، نموذج تواصل، Footer.
يجب أن تعمل بلا إنترنت تماماً.
```

### مثال ج: تحويل تقرير Word إلى صفحة
```text
حوّل محتوى ./report.md إلى صفحة HTML احترافية بنفس هوية ألوان مشروعي
(#1D4ED8 + #0EA5A4)، مع فهرس جانبي لاصق.
```

## 4) نصائح لنتائج أفضل

| افعل | لا تفعل |
|---|---|
| حدّد الجمهور والستايل من البداية | «اعمل لي تقرير جميل» بلا تفاصيل |
| أعطِ كودات HEX إن كانت لديك هوية | الاعتماد على «أزرق» فقط |
| أرفق الشعار والصور وحدّد مساراتها | افتراض أن الوكيل سيجدها |
| اطلب الصيغة النهائية صراحة (Word/PDF/HTML) | ترك الصيغة غامضة ثم الاعتراض |
| راجع الملف وأعد الطلب بتعديل محدد | «مش حلو» بلا تحديد ما يجب تغييره |

### قوالب جاهزة للتعديل السريع

**تعديل لوني بعد التسليم:**
```text
غيّر لون الهوية من #1D4ED8 إلى #7C3AED في كل الملف، وأعد التوليد.
```

**تكثيف/تفكيك:**
```text
المستند طويل جداً. اختصر إلى 3 صفحات مع الحفاظ على كل الجداول والأرقام.
```

**استبدال صورة أو شعار:**
```text
استبدل الشعار بـ ./assets/logo-v2.png وأعد التوليد مع نفس التنسيق.
```

## 5) التحقق اليدوي بعد التسليم

قبل اعتماد أي ملف:

- **Word:** افتحه في Word (لا LibreOffice فقط) وتأكد أن العربية بخط سليم، والعناوين تعمل في لوحة Styles، ورقم الصفحة يتحدّث.
- **PDF:** `pdfinfo file.pdf` → عدد الصفحات والمقاس صحيحان. `pdffonts file.pdf` → كل الخطوط `yes` في عمود `emb`.
- **HTML:** افتحه على الجوال أو صغّر النافذة إلى 375px — لا تمرير أفقي. اطبع إلى PDF مرة لاختبار `@media print`.
